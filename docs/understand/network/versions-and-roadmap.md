# Versions and roadmap

The specifications and the software move together in numbered versions. This documentation is v4.

| Version | Specifications | What it brought | Networks |
|---|---|---|---|
| v3 | Verifiable Trust v3, VPR v3 | The minimum viable model: trust registries, permissions, validation processes, DID directory, trust deposits | the 2025 testnet |
| v4 | Verifiable Trust v4, VPR v4, component specifications | Ecosystems and participants replace trust registries and permissions; corporations as group-governed actors with operators and agents; multi-asset pricing with exchange rates; the Badge credential; VS Agent as a business wallet with vt-flow, OpenID4VC and AnonCreds; indexer with trust resolution and TRQP; the trust graph; the MCP server | devnet, testnet from 13 October 2026 |
| v5 | in preparation | Extended schema authorization policies, council-based governance, tokenomics updates, the visualizer | |
| v6 | 2027 | Trust Spanning Protocol, multi-tenant agents, delegation for AI agents, HSM and enclave custody, vLEI and personhood credentials as additional trust sources | |

The [roadmap](https://github.com/verana-labs/verana-spec/blob/main/ROADMAP.md) in verana-spec is the source for dates and scope. The version dropdown of this site switches between the v4 documentation (current) and the archived v3 pages; v5 appears as "next" when its work starts.
