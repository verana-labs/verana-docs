[TG-FCT-6b] `credentials` group: the non-ECS Verifiable Trust Credentials presented by the DID (`Vtc` records reachable via `Did —REFERENCES_VP→ LVP —CONTAINS_VTC→ Vtc`). ECS credentials (ServiceCredential / OrganizationCredential / PersonaCredential) MUST NOT appear here — they are projected by the `service` and `operator` groups. A presented VTC is by definition held by the DID (no role field). `entries` MAY be truncated to an implementation-defined maximum; `total` always reflects the untruncated population.
