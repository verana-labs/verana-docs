G1 — Validator chain. Ordered `ParticipantRef[]` from **root to leaf inclusive**: the first element has `role = ECOSYSTEM` and `validatorParticipantId = null` (the permission-tree root for the input Participant's Ecosystem; see [[TG-EDGE-4]]); the last element is the input Participant itself. Every element's `ecosystemId` MUST be identical (a validator chain never crosses Ecosystem boundaries). If the input Participant is itself the ECOSYSTEM root, this is a 1-element array containing only the input.
