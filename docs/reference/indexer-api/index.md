# Indexer API

The indexer replays the Verana network, resolves the DIDs it finds, evaluates trust and serves the result over REST and WebSocket. In v4 it also carries trust resolution (the former standalone resolver) and the ToIP Trust Registry Query Protocol endpoint.

The pages in this section are generated from the OpenAPI document published in the [verana-indexer repository](https://github.com/verana-labs/verana-indexer/blob/main/docs/api/openapi.json). The normative description is the [Indexer v4 specification](https://github.com/verana-labs/verana-spec/blob/main/v4/verana-indexer/spec.md).
